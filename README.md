# Public Service Request System (Mini eCitizen-style)

An interactive e-governance platform enabling citizens to report local public issues and county administrators to manage and resolve them.

## 🚀 Links
- **GitHub Repository:** https://github.com/mulwaann/Public-service-requests
- **Live / Deployed URL:** https://public-service-requests.vercel.app

## ✨ Features Implemented
- **Citizen Request Portal:** Submit issues specifying category, location, and description.
- **Admin Dashboard:** Real-time tracking and state workflow updating (`Pending` → `In Progress` → `Resolved`).
- **Analytics Cards:** Instant visual counts for Total, Open, and Resolved cases.
- **Bonus Feature:** Real-time search and filter bar to sort issues by ward, location, or category.
